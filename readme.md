# Flaskr Mini Project

A minimal Flask app (Flaskr) setup tutorial for macOS, with virtual environment and proper folder structure.

---

## Project Structure

**Important:** The `flaskr/` folder and `venv/` must be at the **same level** in your project root.

```bash
python3 -m venv venv       # create virtual environment
source venv/bin/activate   # activate venv (bash/zsh)

pip install Flask
flask run
 * Running on http://127.0.0.1:5000/
